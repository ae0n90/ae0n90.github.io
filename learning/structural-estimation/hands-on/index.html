模块 6

实例：农机服务采纳模型

本模块用模拟数据完成一个完整的结构估计：生成数据、最大似然估计、检验拟合、计算补贴反事实，并说明模型的适用范围。页面中的实验用于演示，完整的计算由配套的 Stata 和 Python 程序完成。

6.1

问题与数据

问题：随机发放服务代金券使部分农户的净服务价格下降。据此估计价格敏感度与经营规模的收益，并预测普惠补贴下的采纳率和财政成本。

样本：700 个模拟农户。代金券随机分配；服务标价、经营规模、距离和质量均可观测。

选择：是否购买机械化服务。

估计：二元 logit 模型的最大似然估计。页面实验只改变价格与规模两个系数，截距、距离和质量系数固定；配套程序同时估计全部系数。

P(购买ᵢ=1) = Λ[β₀ + α·净价格ᵢ + β·log(1+规模ᵢ) + γ·距离ᵢ + δ·质量ᵢ]
说明：模型的推导、似然函数的数值算例、Newton 迭代、估计结果的解释、反事实的置信区间和蒙特卡洛检验，见 模块 6A。
数据说明：本例的参数真值和外生代金券由程序设定，只用于检验估计方法，不构成实证证据。实际的服务价格通常与未观测的质量、需求和供给能力相关，不能直接假定价格外生。

6.4

Stata 程序

Stata 程序使用 logit 命令，该命令最大化二元选择模型的对数似然。程序的重点在于把估计系数解释为效用参数，并用估计参数进行政策模拟。

set seed 20260804
logit adopt net_price ln_land distance quality, vce(robust)

* 给定补贴率 s，重新计算净价格与预测概率
gen phat_cf = invlogit(_b[_cons] + _b[net_price] * listed_price * (1-s) ///
    + _b[ln_land] * ln_land + _b[distance] * distance ///
    + _b[quality] * quality)

完整脚本还会输出按价格四分位的拟合表和 0–50% 补贴率的反事实 CSV/图形。

6.5

Python 程序

Python 程序只使用标准库，显式计算得分向量和信息矩阵，用 Newton–Raphson 法更新参数，无须安装其他软件包。对于更复杂的模型，可将同样的目标函数交给 SciPy 等优化库。

score, information = score_and_information(theta, farmers)
step = solve_linear_system(information, score)
theta = [value + change for value, change in zip(theta, step)]

if max(abs(change) for change in step) < tolerance:
    break

6.7

模型的局限

  • 服务商进入：补贴提高需求后是否有新服务商进入？静态需求模型没有供给方。
  • 容量与拥堵：旺季服务供给有限时，补贴可能抬价或延迟作业。
  • 价格内生性：真实标价可能随未观测需求和质量变化，需要工具变量、实验价格或联合供需模型。
  • 动态学习：农户可能先试用再更新质量认知，需要动态学习模型。
  • 福利：采纳率不是福利。完整福利分析还需服务收益、成本、财政机会成本和供给者剩余。
扩展的顺序：应先完成并检验外生价格下的静态模型，再逐一加入价格内生性、未观测异质性、动态学习或服务商进入。同时加入多项扩展会使识别和计算问题难以诊断。相关模型见常见的扩展模型。

学习要求：能够运行至少一个配套程序，并解释估计、拟合、反事实和适用范围四类结果。
