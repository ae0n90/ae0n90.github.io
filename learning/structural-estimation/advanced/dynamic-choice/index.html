第 B 章

动态离散选择模型

迁移、上学、采用灌溉技术、更换水泵或退出农业等决策都会改变未来的状态。当本期选择影响未来的选择集或收益时，决策者需要比较各选项的未来价值，这时应使用动态模型。模型中含有滞后变量并不足以使其成为动态决策模型。

B.1

何时需要动态模型

动态

采用灌溉技术

本期支付固定成本，未来多年受益；经验、债务和设备状态也随选择变化。

动态

子女上学或工作

上学积累人力资本，工作积累经验和收入；本期选择改变未来的工资。

未必动态

一次性消费选择

若本期选择哪家服务商不影响未来的价格、经验或选择集，静态模型即可。

常见误解

面板数据与动态模型

面板数据和滞后因变量可以描述持续性；动态决策模型则需要明确设定未来价值和状态转移。

B.2

Bellman 方程

V(s, ε) = maxₐ { 当期收益 u(a,s,ε;θ) + β × E[V(s′,ε′) | s,a] }
符号含义农业技术采用中的例子
s决策时已知、影响未来的状态变量是否已采用、资产、经验、信贷状态
a本期可选的行动采用 / 等待 / 退出
u本期净收益产出收益减安装费和借款成本
s′下一期的状态设备老化、经验增加、债务变化
β折现因子：下一期一单位收益在本期的价值β 越高，越重视长期收益
状态变量的充分性：给定本期状态和行动，过去的历史不应对下一期状态有额外的预测力。若遗漏了影响未来的债务或经验等变量，Bellman 方程就不能正确刻画决策问题。

B.4

模型的求解

有限期：逆向归纳

估计参数需要先求出给定参数下的最优选择。有限期模型从最后一期开始求解，再把结果代入倒数第二期，依次向前递推（backward recursion）。教育、生育和生命周期模型常用此法。

无限期：不动点

环境在各期重复出现时，价值函数是 Bellman 算子的不动点。设备更换、企业经营等问题常用价值函数迭代或策略函数迭代求解。

两种基本求解方法
方法每次迭代的计算更新的对象
VFI：价值函数迭代由上一次迭代的价值函数计算新的价值函数，直至前后两次之差小于容差各状态的价值
PFI：政策函数迭代先计算给定策略的价值，再据此改进各状态下的最优行动各状态下的行动

折现因子小于 1 且满足常见条件时，Bellman 算子具有压缩性质，VFI 会收敛到唯一固定点。算法收敛并不说明经济模型正确，也不说明参数已被识别。

B.5

估计方法：NFXP、CCP 与 NPL

经典设备替换模型常假定：当期不可观测冲击可加、冲击服从极值分布，并且给定状态与行动后，下一期状态不再依赖当期冲击。在这些假设下，动态选择概率具有 logit 形式，其中的效用项包含继续价值。

方法做法主要缺点
NFXP对每组 θ，内层求解 Bellman 不动点；外层最大化似然函数两层嵌套，计算量大
Hotz–Miller / CCP先从数据估计条件选择概率，再反演价值差不必反复求解模型，但第一步的估计误差会影响第二步
NPL在伪似然估计与选择概率更新之间迭代计算量介于两者之间；需检查收敛性和有限样本性质
有限期逆向求解与模拟从最后一期递推，可容纳较复杂的类型和冲击状态变量增多时计算量急剧上升（维数灾难）
条件选择概率（CCP）：处于状态 s 时选择行动 a 的概率。在静态 logit 中，它只由当期效用决定；在动态模型中，它还取决于未来价值。
B.6

动态模型需要检查的六个方面

  1. 时间单位：月、季、年会改变折现、状态转移和冲击含义。
  2. 状态空间：哪些变量影响未来？连续状态变量如何离散化或插值？
  3. 状态转移：哪些转移由选择造成，哪些是外生过程？
  4. 初始条件与永久类型：第一期状态是否与未观测偏好相关？
  5. 识别：固定成本、每期收益和 β 分别由哪些跨期选择变化识别？β 通常需要外部校准或有较强的外生变化。
  6. 计算检验：初值、容差、网格和模拟次数是否影响参数估计与反事实结果？蒙特卡洛检验能否得到接近真值的估计？
常见的过度解释：采用行为的持续性不足以证明存在习惯或学习。永久异质性、转换成本、状态依赖和测量误差都可能产生相似的选择路径，需要额外的外生变化才能区分。
