第 C 章

进入博弈

农户需求模型把价格和服务商数量视为给定。进入博弈研究服务商是否进入某一市场：由于竞争会改变各家的利润，一家服务商的最优选择取决于其他服务商的选择。

C.1

从单一决策者到策略互动

普通选择模型

给定价格、距离和质量，农户在自营与购买服务之间选择。其他人的选择一般作为外生的环境变量。

博弈模型

服务商 A 的进入利润取决于 B 是否进入，B 的决策同样取决于对 A 的预期。每个参与者都选择对他人行动的最优反应。

企业 i 进入，当进入利润 πᵢ(进入, 对手行动, 市场 X; θ) ≥ 不进入利润 0

纳什均衡是这样一组选择：给定其他参与者的选择，任何一家都不能通过单方面改变自己的选择而提高利润。均衡并不要求各方的利润最大化总利润。

C.2

完全信息与不完全信息

Complete information

完全信息

两家都知道市场需求以及双方的成本，并且这些是共同知识。研究者仍可能观测不到其中一部分。

Incomplete information

不完全信息

A 观测到自身的成本冲击，对 B 的冲击只知道其分布。因此 A 的最优反应取决于 B 的进入概率，而不是 B 的确定行动。

贝叶斯纳什均衡：每家根据自己的信息和对对方行动的信念作最优选择，且信念与均衡选择概率一致。均衡可写成不动点 p = Ψ(p, X; θ)。

C.4

多重均衡

若一家独占时盈利、两家同时进入时亏损，“只有 A 进入”和“只有 B 进入”都是均衡。多重均衡是模型本身的性质，不是数值计算的问题。此时同一组市场特征和参数对应多个可能的结果，而写出似然函数需要知道每个结果出现的概率。

处理方法需要的额外假设识别结果
指定均衡选择规则设定市场在多个均衡中如何选择可能点识别，但结论依赖于所设定的规则
引入私人信息冲击（不完全信息）设定信息结构与冲击分布，求解概率不动点选择概率是参数的光滑函数，但仍可能有多个不动点
矩不等式只利用均衡必须满足的利润符号条件不需要均衡选择规则，但通常只能集合识别
标准误与均衡选择：标准误小并不说明均衡唯一。若程序隐含地选取了某一个均衡，它可以在该均衡附近给出很小的标准误，但并未说明市场为什么处于这一均衡。
C.5

矩不等式与集合识别

矩不等式方法不要求矩条件精确等于零，只要求观测到的选择满足最优性。若观测到 A 进入，则给定对手的行动，A 进入的利润不低于不进入的利润；若 A 未进入，则其进入利润不大于零。对许多市场的这些符号条件取平均，即得到矩不等式。

观察到进入：E[z·πᵢ(θ) | entry] ≥ 0　；观察到不进入：E[z·πᵢ(θ) | no entry] ≤ 0

满足这些条件的参数通常构成一个集合，因此参数是集合识别的。识别集反映了在较弱的假设下，数据能够排除哪些参数值。

集合识别下的政策分析：对识别集中的每一组参数计算补贴或道路改善的反事实，报告预测值的范围。若各政策的排序在整个识别集内不变，结论仍然可靠；若排序发生变化，则应报告无法判断。
C.6

不完全信息博弈的估计方法

方法做法主要问题
嵌套固定点对每组参数求出全部均衡，再计算似然计算量大，均衡可能随参数不连续变化，直接使用 NFXP 很困难
约束优化以均衡条件为约束，对参数和选择概率同时优化维数高，需检查约束和局部最优
两步 PML / 最小距离先非参数估计进入概率，再估计利润参数第一步的估计误差和市场状态稀疏会影响第二步
NPL在伪似然估计与进入概率更新之间迭代可能收敛到不同的不动点，需使用多组初值
C.7

在农机服务市场中的应用

将进入博弈用于农机服务市场，对数据的要求高于农户需求模型：

  1. “市场”应定义为服务商进入决策相互影响的地域和季节范围，而不是任意的行政区。
  2. 对每个潜在进入者，同时记录其进入和未进入的市场；只使用在营企业的数据会丢失选择集的信息。
  3. 区分需求侧变量（种植面积、作物、地形）与企业成本变量（距离、油价、机械存量）。
  4. 考虑企业类型的差异：本地合作社、跨区作业机手和平台服务商的成本不应假定相同。
  5. 补贴反事实应说明补贴对象是农户还是服务商，以及补贴改变的是需求、固定成本还是竞争强度。
若进入有沉没成本，企业是否继续经营取决于过去的市场状态，则静态博弈不再适用，需要使用动态博弈模型，其计算和识别都更为困难。
