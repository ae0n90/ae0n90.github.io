Route C · 约 50 分钟

进入博弈我的最优选择取决于你怎么选

农户需求模型把价格和服务商数量当作给定；进入博弈进一步问：看到同一批村庄，两家服务商会不会进入？竞争本身会改变每家的利润。

From one agent to many

单一行动者模型哪里不够了？

普通选择模型

给定价格、距离和质量，农户选自营或购买。其他人的选择通常被放进环境变量。

博弈模型

服务商 A 的进入利润取决于 B 是否进入，B 也在预测 A。每个人都在对别人作最佳反应。

企业 i 进入，当进入利润 πᵢ(进入, 对手行动, 市场 X; θ) ≥ 不进入利润 0

“均衡”不是大家都赚钱最多，而是给定别人当前的选择，没有任何一家愿意单方面改变自己的选择。

Information structure

完全信息与不完全信息，差在谁看见了什么

Complete information

成本大家都知道

两家都知道市场需求、自己和对方成本，也知道对方知道这些。研究者可能仍有未观察量。

Incomplete information

各自知道自己的私人成本

A 看见自己的临时冲击，但只知道 B 冲击的分布。最优反应取决于对方进入概率而非确定行动。

贝叶斯纳什均衡：每家基于自己的信息和对对方的信念作最优选择，而且这些信念与最终选择概率互相一致。常写成固定点 p = Ψ(p, X; θ)。
Interactive entry game

市场足够养活一家，却养不活两家时，会发生什么？

Multiple equilibria

多重均衡不是优化器故障，而是模型真的允许多个结果

当独占有利、两家竞争却亏损时，“只有 A 进”和“只有 B 进”都能自我维持。相同市场特征和参数对应多个可观察结果，直接似然却需要知道每个结果出现的概率。

处理办法额外要求能得到什么
指定均衡选择规则说明市场怎样在多个均衡中选一个可能点识别，但结论依赖规则
加入私有冲击/不完全信息设定信息与冲击分布，解概率固定点选择概率平滑，但仍可能多固定点
矩不等式只用均衡必须满足的利润符号较少选择规则，但通常是集合识别
小标准误不能证明唯一均衡：若程序暗中选了某一个解，它可以在这个解附近给出很精确的标准误，却没有解决“为什么市场会选这个解”。
Moment inequalities

矩不等式：不强求精确等于零，只要求观察选择没有明显违背最优性

若观察到 A 进入，在给定对手行动下，A 的进入利润应至少不低于不进入；若 A 没进入，反过来的利润差应不大于零。把许多市场的这些符号限制平均起来，就得到矩不等式。

观察到进入：E[z·πᵢ(θ) | entry] ≥ 0　；观察到不进入：E[z·πᵢ(θ) | no entry] ≤ 0

一整片参数都可能满足这些限制，所以结果是“参数集合”，不是唯一点。集合识别不是失败：它诚实显示数据和弱假设到底排除了多少。

区间的政策含义：对每个可接受参数都做补贴或道路改善反事实，报告预测范围。若政策排序在整个集合内都相同，结论仍可能很强；若排序翻转，应报告无法确定。
Computational routes

不完全信息博弈的常见估计路线

路线直觉主要风险
嵌套固定点每组参数都找所有均衡，再算似然昂贵、解可能跳跃，直接 NFXP 很难
约束优化把参数、选择概率和均衡条件一起交给优化器维度大，约束与局部最优需诊断
两步 PML / 最小距离先非参数估计进入概率，再估利润参数第一步误差和稀疏市场状态会传递
NPL在伪似然参数与进入概率更新间迭代可能收敛到不同固定点，需多初值
Agricultural service markets

把这个模型用于农业服务市场，数据要升一级

  1. 把“市场”定义为服务商进入决策真正相互影响的空间与季节范围，而非任意行政区。
  2. 为每个潜在进入者同时记录进入和未进入市场；只看在营企业会丢掉选择集合。
  3. 区分需求侧变量（种植面积、作物、地形）与企业成本变量（距离、油价、机械存量）。
  4. 考虑企业身份与不对称性：本地合作社、跨区机手和平台服务商的成本不能强行设为相同。
  5. 补贴反事实必须说明补贴给农户还是服务商，以及它改变需求、固定成本还是竞争强度。
若进入具有沉没成本、企业会根据过去市场状态续营，静态博弈仍不够；这时要进入动态博弈，计算和识别难度都会明显上升。
