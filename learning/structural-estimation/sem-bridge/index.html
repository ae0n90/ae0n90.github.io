模块 6B

结构方程模型

农业经济学文献中的结构方程模型（SEM）通常指：用多个问卷题项测量态度、意愿等潜变量，再估计潜变量之间的路径系数。SEM 与结构估计都先设定数据生成过程，再选择参数使模型与数据尽量一致；但两者的参数含义、识别来源和所能回答的问题不同。本章介绍 SEM 的基本原理、自由度的计算和估计结果的解释，并给出 R lavaan 与 Python semopy 程序，两者的结果相互一致。

6B.1

结构估计与结构方程模型的比较

结构估计（模块 1–7）结构方程模型（SEM）
出发点经济行为：效用、约束、信息、均衡测量：多个题项共同反映一个不可直接观测的构念
参数价格敏感度、成本、贴现率等行为参数因子载荷、潜变量间路径系数、误差方差
拟合的对象选择概率（MLE）、矩（GMM/SMM）样本协方差矩阵 S 与模型隐含协方差 Σ(θ)
识别来源外生价格变化、实验、排除性限制题项数与参数数的计数、载荷归一化、“无路径”的限制
典型用途未实施政策的反事实验证量表、检验理论路径（如 TPB）与中介
最常见误用反事实超出数据支持把截面相关的路径系数读成因果效应
6B.2

潜变量与测量误差

“农户对托管服务的态度”不能直接测量。问卷用三道题（“托管省心”“托管划算”“我喜欢托管”）测量，每题按 1–7 分作答。每道题既反映态度，也含有各自的测量误差。SEM 把三道题的共同变异归于潜变量“态度”，把各题特有的变异归于测量误差。这样估计的“态度 → 意愿”路径系数不会因测量误差而向零偏误（衰减偏误）。

与结构估计的共同点：两者都先设定数据生成过程，再选择参数，使模型隐含的数据特征与样本的数据特征最接近。在 SEM 中，这些数据特征是全部题项的方差和协方差。
6B.3

测量方程、结构方程与协方差矩阵

测量模型： x=Λη+ε结构模型： η=Bη+ζ

x 是题项，η 是潜变量，Λ 是载荷矩阵，B 是潜变量间路径。代入后，模型隐含的题项协方差矩阵为

Σ(θ)=Λ(I−B)−1Ψ(I−B)−1′Λ′+Θε​

最大似然估计让 Σ(θ) 尽量接近样本协方差 S：

FML​(θ)=ln∣Σ(θ)∣+tr(SΣ(θ)−1)−ln∣S∣−p,χ2=(N−1)FML​(θ^)

这与模块 4 的 GMM 类似，都是最小化模型隐含的数据特征与样本数据特征之间的距离。区别在于 SEM 使用的特征是二阶矩，距离函数由多元正态似然导出。

6B.4

自由度与识别

p 个题项提供 p(p+1)/2 个不重复的方差和协方差。每个潜变量的第一个载荷固定为 1，以确定潜变量的尺度（与 logit 模型固定误差方差的作用相同）。

模型题项 p样本矩自由参数df
Holzinger–Swineford 三因子 CFA9456 载荷 + 9 误差方差 + 3 因子方差 + 3 因子协方差 = 2124
TPB 采纳意愿（ATT、SN、PBC → INT）12788 载荷 + 12 误差方差 + 3 外生方差 + 3 外生协方差 + 3 路径 + 1 扰动方差 = 3048

两个模型的 df 都与软件输出一致。df ≥ 0 是识别的必要条件（df = 0 时模型恰好识别，无法检验拟合）。对每个题项只载荷于一个因子、测量误差互不相关的模型，“每个潜变量至少三个题项”是常用的充分条件。

6B.5

例一：Holzinger & Swineford（1939）数据

301 名学生的 9 项能力测验，数据随 lavaan 发布，是 SEM 教科书和 lavaan 官方教程中的常用例子。三因子：视觉（x1–x3）、文字（x4–x6）、速度（x7–x9）。

lavaan 0.6-19 与 semopy 2.3.11 的拟合结果
指标lavaansemopy常用参考（Hu & Bentler 1999）解释
χ²（df）85.306（24）85.306（24）p 值不显著p < 0.001，模型与数据有显著差异；但 χ² 统计量对样本量敏感

两个软件的 χ²、CFI、TLI、RMSEA 完全一致，lavaan 的数字也与 lavaan 官方 CFA 教程一致。标准化载荷中 x2 只有 0.424，是视觉因子最弱的题项。

修正指数

最大的修正指数是“视觉 → x9”（MI = 36.4）。加上这条交叉载荷后 χ²(23) = 52.382，CFI = 0.967，RMSEA = 0.065，SRMR = 0.045；χ² 差异检验 Δχ² = 32.9，p ≈ 1×10⁻⁸。

修正指数的使用：修正指数只提示可能的模型误设。只有新路径有理论依据（例如 x9 题目本身需要空间判断）时才可加入，并应在新样本中复核。按修正指数逐条增加路径，会使模型拟合样本中的随机误差（MacCallum 等，1992）。温忠麟等（2004）也提醒，Hu–Bentler 的截断值不应机械套用。

例二：农户托管意愿的计划行为理论模型（模拟数据）

按计划行为理论（Ajzen 1991）设定：态度 ATT、主观规范 SN、知觉行为控制 PBC 影响采纳意愿 INT；每个潜变量 3 个题项，N = 500。真值由程序设定（模拟数据，非真实调查），用于检验估计值是否接近真值。

路径系数的因果解释：本例的数据按“ATT 影响 INT”生成，因此路径系数有因果含义。在实际的截面问卷数据中，态度与意愿可能互为因果，也可能同时受未观测因素影响，路径系数只是模型假设下的条件相关。若需要因果解释，应结合实验、工具变量或面板数据设计，即模块 1 和模块 2 讨论的识别问题。
6B.7

R 与 Python 程序

R · lavaan

library(lavaan)
tpb <- '
  ATT =~ att1 + att2 + att3
  SN  =~ sn1 + sn2 + sn3
  PBC =~ pbc1 + pbc2 + pbc3
  INT =~ int1 + int2 + int3
  INT ~ ATT + SN + PBC '
fit <- sem(tpb, data = dat)
fitMeasures(fit, c("chisq","df","cfi",
                   "tli","rmsea","srmr"))
standardizedSolution(fit)

Python · semopy

import pandas as pd, semopy
desc = """
ATT =~ att1 + att2 + att3
SN =~ sn1 + sn2 + sn3
PBC =~ pbc1 + pbc2 + pbc3
INT =~ int1 + int2 + int3
INT ~ ATT + SN + PBC"""
m = semopy.Model(desc)
m.fit(pd.read_csv("data/tpb_sim.csv"), obj="MLW")
semopy.calc_stats(m).T
m.inspect(std_est=True)

semopy 使用 obj="MLW"（Wishart 似然）时，χ² 与 lavaan 默认 ML 完全相同。注意 semopy 的 inspect() 把载荷写成 x1 ~ visual，记号方向与 lavaan 的 =~ 相反，数值相同。

6B.8

应用中需要注意的问题

测量模型与结构模型先做 CFA，确认 CR、AVE、区分效度，再估路径（Anderson & Gerbing 1988 两步法）。
模型修正每增加一条路径都应有理论依据，并报告修改过程。
李克特量表题项李克特题项是有序变量。5 点以下或严重偏态时，考虑 WLSMV（lavaan 的 ordered=）。
共同方法偏差自变量和因变量来自同一份问卷、同一受访者时，应检验共同方法偏差（Podsakoff 等 2003）。
路径系数与因果效应截面 SEM 中路径的方向来自理论假设，而不是由数据决定。
