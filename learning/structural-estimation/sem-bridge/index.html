结构方程模型（SEM）
名字里也有“结构”，但估计的是另一类对象

农经论文里的“结构方程模型”通常指用问卷题项测量态度、意愿等潜变量，再估计潜变量之间的路径。它和本课程的结构估计共享“先写模型、再让模型与数据对账”的思想，但参数含义、识别来源和能回答的问题不同。本页同样按“直觉 → 公式 → 数字 → 读输出 → 代码”展开，代码用 R lavaan 与 Python semopy 在本机实际运行并互相核对。

Side by side

先分清两种“结构”

结构估计（本课程模块 1–7）结构方程模型 SEM（本页）
出发点经济行为：效用、约束、信息、均衡测量：多个题项共同反映一个不可直接观测的构念
参数价格敏感度、成本、贴现率等行为参数因子载荷、潜变量间路径系数、误差方差
对账对象选择概率（MLE）、矩（GMM/SMM）样本协方差矩阵 S 与模型隐含协方差 Σ(θ)
识别来源外生价格变化、实验、排除性限制题项数与参数数的计数、载荷归一化、“无路径”的限制
典型用途未实施政策的反事实验证量表、检验理论路径（如 TPB）与中介
最常见误用反事实超出数据支持把截面相关的路径系数读成因果效应
Step 1 · Intuition

直觉：一把尺子量不准，就用三把

“农户对托管服务的态度”没法直接量。问卷用三道题（“托管省心”“托管划算”“我喜欢托管”）各打 1–7 分。每道题都含有态度的信号，也含有各自的噪声。SEM 的做法是：三道题共同变化的部分归给潜变量“态度”，各自独有的部分归给测量误差。这样估出的“态度 → 意愿”路径，不会因为测量误差而被系统性压小（衰减偏误）。

与结构估计的共同点：都先写出“数据是怎样生成的”，再找让模型生成的数据特征最接近真实数据的参数。SEM 的“数据特征”就是全部题项两两之间的方差和协方差。
Step 2 · Formalism

两组方程，一个协方差矩阵

测量模型： x=Λη+ε结构模型： η=Bη+ζ

x 是题项，η 是潜变量，Λ 是载荷矩阵，B 是潜变量间路径。代入后，模型隐含的题项协方差矩阵为

Σ(θ)=Λ(I−B)−1Ψ(I−B)−1′Λ′+Θε​

最大似然估计让 Σ(θ) 尽量接近样本协方差 S：

FML​(θ)=ln∣Σ(θ)∣+tr(SΣ(θ)−1)−ln∣S∣−p,χ2=(N−1)FML​(θ^)

这和模块 4 的 GMM 很像：都在最小化“模型给的数据特征”与“样本数据特征”的距离；区别是 SEM 的特征固定为二阶矩，距离由正态似然给出。

Step 3 · Worked numbers

数一数：信息够不够解出参数？

p 个题项提供 p(p+1)/2 个不重复的方差、协方差。每个潜变量的第一个载荷固定为 1 来定尺度（与 logit 固定误差方差同理）。

模型题项 p样本矩自由参数df
Holzinger–Swineford 三因子 CFA9456 载荷 + 9 误差方差 + 3 因子方差 + 3 因子协方差 = 2124
TPB 采纳意愿（ATT、SN、PBC → INT）12788 载荷 + 12 误差方差 + 3 外生方差 + 3 外生协方差 + 3 路径 + 1 扰动方差 = 3048

两者的 df 都与软件输出一致。df > 0 是必要条件；“每个潜变量至少三个题项”是常用的充分规则。

Step 4 · Read the output

真实公开数据：Holzinger & Swineford（1939）

301 名学生的 9 项能力测验，lavaan 自带，是 SEM 教科书和 lavaan 官方教程的标准例子。三因子：视觉（x1–x3）、文字（x4–x6）、速度（x7–x9）。

lavaan 0.6-19 与 semopy 2.3.11 的拟合结果（本机运行）
指标lavaansemopy常用参考（Hu & Bentler 1999）怎么读
χ²（df）85.306（24）85.306（24）p 不显著最好p < 0.001：模型与数据有显著差异；但 χ² 对样本量敏感

两个软件的 χ²、CFI、TLI、RMSEA 完全一致，lavaan 的数字也与 lavaan 官方 CFA 教程一致。标准化载荷中 x2 只有 0.424，是视觉因子最弱的题项。

拟合不足之后：修正指数只是线索

最大的修正指数是“视觉 → x9”（MI = 36.4）。加上这条交叉载荷后 χ²(23) = 52.382，CFI = 0.967，RMSEA = 0.065，SRMR = 0.045；χ² 差异检验 Δχ² = 32.9，p ≈ 1×10⁻⁸。

不要“刷”指标：只有当新路径有理论理由（例如 x9 题目本身需要空间判断）时才可加入，并应在新样本中复核。按 MI 逐条加路径会把模型拟合到样本噪声上（MacCallum 等 1992 的警告）。温忠麟等（2004）也提醒，Hu–Bentler 的截断值不应机械套用。
Step 5 · Agricultural example

模拟教学数据：农户托管意愿的 TPB 模型

按计划行为理论（Ajzen 1991）设定：态度 ATT、主观规范 SN、知觉行为控制 PBC 影响采纳意愿 INT；每个潜变量 3 个题项，N = 500。真值由程序设定（模拟数据，非真实调查），用来检验能否“估回真值”。

路径系数能当因果吗？这里的数据由“ATT 导致 INT”的程序生成，所以可以。真实截面问卷里，态度和意愿可能互为因果、同受未观测因素影响，路径系数只是在模型假设成立时的条件关联。需要因果解释时，应结合实验、工具变量或面板设计——这正是本课程模块 1、2 反复强调的识别问题。
Code

两份代码，同一份数据

R · lavaan

library(lavaan)
tpb <- '
  ATT =~ att1 + att2 + att3
  SN  =~ sn1 + sn2 + sn3
  PBC =~ pbc1 + pbc2 + pbc3
  INT =~ int1 + int2 + int3
  INT ~ ATT + SN + PBC '
fit <- sem(tpb, data = dat)
fitMeasures(fit, c("chisq","df","cfi",
                   "tli","rmsea","srmr"))
standardizedSolution(fit)

Python · semopy

import pandas as pd, semopy
desc = """
ATT =~ att1 + att2 + att3
SN =~ sn1 + sn2 + sn3
PBC =~ pbc1 + pbc2 + pbc3
INT =~ int1 + int2 + int3
INT ~ ATT + SN + PBC"""
m = semopy.Model(desc)
m.fit(pd.read_csv("data/tpb_sim.csv"), obj="MLW")
semopy.calc_stats(m).T
m.inspect(std_est=True)

semopy 使用 obj="MLW"（Wishart 似然）时，χ² 与 lavaan 默认 ML 完全相同。注意 semopy 的 inspect() 把载荷写成 x1 ~ visual，方向记号与 lavaan 的 =~ 不同，数值相同。

Pitfalls

审稿人最常追问的五件事

先测量、后结构先做 CFA，确认 CR、AVE、区分效度，再估路径（Anderson & Gerbing 1988 两步法）。
不按 MI 刷指标每加一条路径都要有理论理由，并报告修改过程。
李克特题项是有序变量5 点以下或严重偏态时，考虑 WLSMV（lavaan 的 ordered=）。
共同方法偏差自变量和因变量来自同一份问卷、同一个人时尤其要检验（Podsakoff 等 2003）。
路径 ≠ 因果截面 SEM 的方向来自理论假设，不来自数据。
